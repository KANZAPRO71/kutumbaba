Kebijakan Privasi — Papua AI

Terakhir diperbarui: 19 Maret 2026

Papua AI (“aplikasi”) adalah teman ngobrol suara yang dikembangkan oleh KANZAPRO71. Privasi ko penting — ringkasan di bawah ini ditulis plain language untuk Play Store dan pengguna.

1. Siapa pengendali data

Pengembang: proyek open source KANZAPRO71/kutumbaba. Untuk pertanyaan privasi: buka issue di GitHub atau kontak yang tercantum di listing Play Store.

2. Data apa yang diproses

  • Suara & obrolan — audio mikrofon dan teks percakapan diproses untuk fitur ngobrol live.
  • Memori lokal — fakta, preferensi, ringkasan sesi, dan “urusan belum selesai” disimpan di perangkat ko (SQLite).
  • Gemini API key (BYOK) — key milik ko, disimpan di perangkat untuk menghubungkan ke Google Gemini.
  • Preferensi app — suara, mode, pengaturan RAG, notifikasi check-in (jika diaktifkan).
  • Lokasi perkiraan — hanya jika ko izinkan; dipakai untuk konteks situasi (mis. cuaca/gerak), tidak dibagikan ke server developer.

3. Di mana data disimpan

Backend percakapan berjalan di HP ko (server lokal di perangkat), bukan di server developer. Memori dan sesi disimpan lokal di perangkat.

4. Pihak ketiga

Saat ko ngobrol, konten (suara/teks) dikirim ke Google Gemini API menggunakan API key milik ko, sesuai Kebijakan Privasi Google dan Ketentuan Gemini API. Developer Papua AI tidak menerima salinan obrolan ko di cloud milik developer.

5. Izin perangkat

  • Mikrofon — wajib untuk panggilan suara.
  • Internet — koneksi ke Gemini API.
  • Notifikasi — opsional, untuk check-in harian lembut (bisa dimatikan di pengaturan).
  • Lokasi — opsional; hanya jika ko beri izin di Android.

6. AI-generated content

Respons dihasilkan oleh model AI (Gemini). Bisa salah atau tidak sesuai konteks. Jangan andalkan untuk nasihat medis, hukum, atau keuangan. Ko bisa hapus memori lokal di Pengaturan.

7. Cara meminta penghapusan data (Papua AI)

Aplikasi: Papua AI · Pengembang: KANZAPRO71. Developer tidak menyimpan obrolan ko di server cloud milik developer. Sebagian besar data ada di HP ko; ko bisa hapus sendiri tanpa email ke developer.

Langkah di perangkat (disarankan):

  1. Buka Papua AI → ikon Pengaturan (roda gigi).
  2. Memori / RAG: hapus ingatan per item atau kosongkan daftar memori yang ditampilkan.
  3. API key: hapus isi field Gemini API Key lalu simpan, atau ganti key baru.
  4. Notifikasi harian: matikan toggle jika tidak ingin pengingat.
  5. Hapus semua data app: uninstall Papua AI dari Android (Settings → Apps → Papua AI → Uninstall).

Data apa yang dihapus vs disimpan:

  • Dihapus saat langkah di atas / uninstall: memori lokal, ringkasan sesi, preferensi app, API key di perangkat, database SQLite app.
  • Tidak disimpan developer: salinan obrolan di cloud KANZAPRO71 — tidak ada.
  • Google Gemini: suara/teks yang sudah dikirim ke Gemini API memakai key ko tunduk kebijakan & alat Google. Untuk data di sisi Google, kelola lewat Akun Google / dokumentasi Google AI Studio.

Retensi: data lokal tetap ada sampai ko hapus atau uninstall. Developer tidak menetapkan periode retensi server untuk obrolan (karena tidak dikumpulkan di server developer).

Bantuan tambahan: buka issue GitHub kutumbaba (cantumkan “Penghapusan data Papua AI”) atau kontak email di listing Play Store.

8. Retensi umum

Backup Android cloud untuk preferensi BYOK di-exclude dari backup app (lihat aturan backup di APK).

9. Anak-anak

Aplikasi tidak ditargetkan untuk anak di bawah 13 tahun. Orang tua/wali bertanggung jawab atas penggunaan dan API key.

10. Perubahan

Kebijakan ini bisa diperbarui. Versi terbaru ada di halaman ini.
