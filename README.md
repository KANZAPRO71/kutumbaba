# Kutumbaba Studio

AI-powered mobile app builder for Indonesian builders (UMKM & mahasiswa).

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Mock AI prompt → app preview (no backend required)

## Commands

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint
npm test
npm run build
```

## Demo flow

1. Open Studio and click **Mulai di Studio**
2. Send a prompt such as `Buat toko online sederhana dengan daftar produk`
3. Wait for the build, then use **Add to Cart** / **Add Produk**
